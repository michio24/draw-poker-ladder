# ドローポーカー・ラダー ゲーム仕様書

Oct 1, 2026 · @Michio

## 概要

1枚ずつ100コインを払ってカードを買い足し、5枚の役で払い出しを受けるソロ用ポーカー（仮称：ドローポーカー・ラダー）。最適戦略でRTP 96.47%、簡易戦略でも96.0%になる配当表を確定した。

- 核となる緊張感：「あと100枚払って次の1枚を見るか、ここで損切りするか」を最大3回判断する
- 降りても既ベットは戻らない（サンクコスト）。正しく降りるとRTPが約8ポイント上がり、技術介入の余地になる
- 開始枚数は2枚を採用。1枚開始だと最初の判断がほぼ常に「続行」で意味を持たないため（6章で比較）

## 基本ルールとゲームフロー

1ラウンドの最大ベットは400コイン（100×4回）、最小は100コイン。

1. **開始ベット**：100コインを払うと、シャッフル済みの52枚デッキ（ジョーカーなし）から2枚が表向きで配られる
2. **判断①（2枚時点）**：100コイン払って3枚目を引くか、降りるかを選ぶ
3. **判断②（3枚時点）**：同様に4枚目を引くか降りる
4. **判断③（4枚時点）**：同様に5枚目を引くか降りる
5. **役判定**：5枚揃った時点で役を判定し、配当表の固定コインを払い出す（配当はベット返却込みの総額）
6. **降りた場合**：その時点で終了、払い出し0。支払ったベットは没収

補足仕様：

- 1ラウンドごとに新しいデッキを使う（RTP計算の前提）
- 交換（ドロー）はない。引いたカードはすべて手札に残る
- J-Aのペア以上が成立した時点で勝ちが確定し、以降は自動でベットして5枚目まで引く（6章）
- 判断中はEVを表示せず、ラウンド後に答え合わせを表示する（6章）

## RTPと確率分析

最適戦略でのRTPは96.47%（目標96.5%との差 −0.03pt）。数値はシミュレーションではなく、全259万通りの5枚組を列挙した厳密計算（後退帰納法）による。

| プレイの仕方 | RTP | 平均ベット／ラウンド | 平均払い出し |
| --- | --- | --- | --- |
| 最適戦略（EV最大化） | 96.47% | 281.7 | 271.8 |
| 簡易戦略（5章のルール） | 96.01% | — | — |
| 一切降りない | 88.62% | 400.0 | 354.5 |

RTPは「総払い出し ÷ 総ベット」で定義する。降りたラウンドのベットも分母に含む。

ラウンドの主要指標（最適戦略）：

- 勝率（払い出しあり）：15.9%。払い出しは最小でも1,000なので、当たれば必ずプラス収支
- 5枚目まで到達：46.5%。2枚時点で30.8%、3枚時点で3.2%、4枚時点で19.5%が降りる
- 1ラウンド収支の標準偏差：約1,575コイン（平均ベットの5.6倍）。ビデオポーカー（Jacks or Better）より高ボラティリティ
- 期待損失：1ラウンドあたり約10コイン

## 最適戦略と簡易戦略

次の3行を守るだけでRTP 96.0%となり、最適との差は0.46ptに収まる。ここでの「絵札」はJ・Q・K・Aを指す。

| 判断時点 | 続行する条件（いずれか1つ） | 降りる手 |
| --- | --- | --- |
| 2枚 | ペア／同スート／絵札1枚以上 | 10以下のオフスート2枚（例：3♠8♥） |
| 3枚 | ペア／3枚同スート／絵札1枚以上 | 10以下のみ・スート不揃い（つながり次第で一部続行） |
| 4枚 | ペア以上／4枚同スート／ストレート待ち／絵札2枚以上 | 役なし・ドローなしで絵札1枚以下 |

4枚時点の続行EV（参考、払い戻し後の正味）：

- J-Aペア：+1,117 ／ 2-10ペア：+283 ／ 4枚同スート：+1,306〜+1,494
- 両面ストレート待ち：+733〜+921 ／ 内側ストレート待ち：+317〜+567
- 絵札2枚：+25 ／ 絵札1枚：−37.5 ／ 絵札0枚：−100（5枚目で役が作れない）

「絵札2枚なら続行、1枚なら降り」がこのゲームで最も際どい判断になる。サンクコストに引きずられて続けるプレイヤーとの差がここで生まれる。

## 設計上の論点と代替案

配当は感度が高く、下位役を1段階変えるだけでRTPが数ポイント動く。調整は下位役から行う。

| 変更 | RTPへの影響 |
| --- | --- |
| スリーカード 3,000 → 3,200 | +1.1pt |
| ツーペア 2,000 → 2,200 | 約+2.5pt |
| J-Aペア 1,000 → 1,100 | 約+3.6pt |
| ロイヤル 500,000 → 1,000,000 | 約+0.3pt |

検討した代替案：

- **1枚開始（最大500ベット）**：同じ配当表ではRTP 62.5%。96.5%にするには配当全体を約1.3倍にする必要がある。1枚目の時点での判断はほぼ常に続行なので、判断回数が実質1回減る
- **2-10ペアにも払い出し（例：400＝最大ベット返却）**：払い出しのあるラウンドが約46%まで増え遊びやすくなる。一方で降りる価値がほぼ消え（最適と「降りない」の差が0.1pt未満）、このゲームの核である損切り判断が無意味になるため不採用
- **配当をベット比で表示**：ラウンドごとに総ベットが変わるため、固定コイン表示の方が直感的。UIでは「この5枚目を引けば最大◯倍」のように現在の総ベット比を併記するとよい

決定事項：

- **情報表示**：判断中は推奨もEVも出さない。ラウンド終了後に各判断の答え合わせ（正誤と続行EV）を表示する。アウツ（次の1枚で各役が成立する確率）は設定でONにできる。推奨アイコンはチュートリアルの最初の数ラウンドだけ
- **RTP表記**：画面に出す場合は「最適プレイ時 96.47%」と明記する（降りないプレイでは88.6%）
- **ジャックポット**：ロイヤルフラッシュは固定1,000,000。オンラインの共通プールを導入するときに、シード500,000＋ベットの0.3%積み立てで再計算する
- **勝率15.9%**：許容し、現行配当を維持。J-Aペアを200や400に下げる案は、勝率が約5%まで落ち、5枚目到達も半減するため不採用
- **確定ラウンド**：最初の2枚でJ-Aペア（55回に1回）なら勝ちが確定する。避けずに確定演出として活かす

* **確定ラウンドの操作**：J-Aペア以上が成立した時点で、5枚目まで自動でベットして引く（AUTO表示）。最適プレイと同じ行動なのでRTPは不変。自動分は答え合わせと連続正解の対象外。所持コインが足りない場合は、不足分を払い出しから差し引く（最低配当1,000＞残りベット最大300なので、必ずプラスで終わる）

| 項目 | 仕様 |
| --- | --- |
| 初期所持コイン | 20,000 |
| 破産時の救済 | 所持が400未満になったら、ボタン1つで10,000まで無料補充（待ち時間・広告なし） |

| テーブル | 100／1,000／10,000の3卓。所持コインで解放。配当は比例し、RTPは全卓共通 |
